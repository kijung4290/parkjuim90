# 초기 디자인 시안 (보관용)

이 폴더의 HTML은 사이트를 만들기 전에 비교했던 디자인 시안입니다.

원래는 `public/`에 있었지만, 그 위치에 두면 `https://parkjuim90.cloud/test.html` 같은 주소로
누구나 접근할 수 있고 검색엔진도 색인합니다. 시안에는 지금 쓰지 않는 브랜드명
("박주임의 현장 도구작업실")과 예전 문구가 남아 있어서, 색인되면 검색 결과에서
브랜드 신호가 갈라집니다. 그래서 배포되지 않는 이 폴더로 옮겼습니다.

보고 싶을 때는 브라우저로 파일을 직접 열면 됩니다. 서로 연결된 `test.html`의
"← 시안 비교" 링크도 같은 폴더 안에서 동작합니다.
